# 织律 · Ruleweaver

2D 横向探索建造沙盒：玩家组合规则，创造物质与行为。

**当前为 v0.13 可操作开发场景：可见角色、地形、水位、中文工具栏、织律台与真正可编辑的节点图已接入同一世界。画面是简化程序化素材，不是概念图成品或正式发行。**

## 打开游戏

使用锁定的 Godot 4.6.1 导入 `godot/project.godot`，按 F6/F5 运行 `presentation/main.tscn`，或者：

```sh
/path/to/godot --path godot
```

Actions 的 `playable-windows-<commit>` 工件在原生测试之后生成自包含开发运行包：解压其中的 `Ruleweaver-v0.13-windows-x86_64-development.zip`，运行 `Start_Ruleweaver.bat`。内附官方引擎，无需另装编辑器；这是“官方引擎运行源码”的开发包，不冒称优化导出、签名安装器或 Stable Release。以对应提交的实际打包结果为准。

首次进入暂停。点击“继续探索”开始。

| 操作 | 按键 / 界面 |
|---|---|
| 移动 / 跳跃 | A、D / 空格；方向键也可用 |
| 选择工具 | 1～7 或底部工具栏 |
| 挖掘、放置、取水、排水 | 选择工具后左键点击世界 |
| 收回造物 | 右键点击造物 |
| 编织规则 | Tab / E / 织律台按钮 |
| 保存 / 载入 | F5 / F9；载入前确认 |
| 暂停 / 单步 | 顶部按钮；Esc 暂停 |
| 调整显示比例 | 世界区域滚轮 |

## 首段探索

地图有 6,000 单位环境水，角色初始携带空容器、便携灯和 20 石料。目标是携灯到访右侧遗迹，然后回营地交水 500。不要把此场景说成已经实现“从零采集制造”。

可先把容器放在水面上方的空格（例如角色附近的 `(1,-1)`），打开织律台，使用或拆改“限量吸水”草稿，点击“应用到造物”，收起织律台后让程序运行。水位下降后收回装水的容器，放灯、进入遗迹、返回营地交水。也可以直接挖开地板排水，或者手工搬水；目标不检查指定配方。

织律台编辑时世界暂停。初始结构仅为可拆改的普通规则图；“节点与连线”中可添加节点、拖动端口连线、断线、修改参数，选中节点后 Delete 删除。被引用的节点需先断线。草稿校验和预览不修改世界，“应用”才发布不可变新版本并绑定所选造物。

**尚未应用的草稿只保留在本次会话。** 世界存档保存已发布规则、身份、水量、位置、时钟、目标和角色速度。律卷导入不会自动绑定；导出已有文件须明确覆盖。新探索会清空当前未保存进度，但不会删除磁盘存档。

## 自动检查

Python 3.11+，标准库，无 pip 依赖：

```sh
python tools/run_checks.py --offline-only
python tools/run_checks.py --godot /path/to/godot
python tools/package_desktop.py --godot /path/to/godot --output packages
```

Windows 可使用 `Godot_v4.6.1-stable_win64_console.exe`。`python tools/install_godot.py --destination .tools/godot` 下载并校验固定官方归档。退出0为请求范围通过，1失败，2原生环境受阻；离线通过不等于引擎通过。

真实UI验收覆盖鼠标工具栏/世界点击、键盘移动、原生GraphEdit端口拖动、草稿应用、抽水途中磁盘恢复、到访遗迹和交水。测试不替代真实设备、最终美术或手感验收。详细边界见 `docs/INTERFACE.md` 和 `docs/STATUS.md`。

## 工程与许可

`runtime/` 保存唯一世界、规则、资源和存档；`presentation/` 只负责显示、编辑和调用这些服务，不维护第二份水量或库存。正式运行不依赖 Python、tests 或 scenarios。旧协议和旧路线测试继续保留。

有限场景、有限原语和全快照事务仍有规模上限，没有无限地形、多人、声音、游泳、最终美术或大世界性能结论。当前可操作不等于整款游戏已完成。

第三方工程代码见 `THIRD_PARTY_NOTICES.md`、`vendor_manifest.json` 和 `godot/vendor/coheronia/`。不包含上游美术、音乐和剧情。开发运行包从实际引擎读取 Godot 许可与第三方版权；字体使用操作系统已安装字体，不分发字体文件。新代码整体发行许可尚未单独确定，第三方许可不变。
