# v0.13 显示、织律台和开发运行包

## 已实现的产品边界

首次可从主场景直接操作，不再只运行隐藏测试。沿用已展示的候选配色、左右布局和信息层级，采用简化程序绘制的地形、角色、水面、容器及遗迹。此批没有把概念图中的复杂像素美术、虚构完成标记或虚构测试数字当成实现目标或事实。用户“继续”作为推进现有候选方向的授权，不作为最终审美/手感验收。

WorldCanvas每帧从WorldSession只读采样，水位来自实际整数账本；角色脚点来自已验证的CharacterBody2D/亚格占位。绘制不修改碰撞。波纹和光晕是提示性动效，不宣称完整GPU灯光或真实光遮挡。有限场景显示窗口不是流式大世界。

## 编辑与应用

LoomDocument包装既有RuleDraft。限量吸水、暗处发光、向右排水仅创建普通节点/引用/动作数组，玩家可拆改；没有增加专门的泵配方执行器。右侧卡片是当前图的分类摘要，不是可拖动连线本身；实际自由编辑在原生GraphEdit窗口。

GraphEdit的端口类型和标签取自RuleCompiler.signature。连线请求写回RuleDraft，断线产生可暂存但不能发布的不完整草稿。参数、方向和模块选择写入config；动作按创建顺序执行。未提供完整的函数签名编辑UI或全部状态能力扩展；内核边界仍以RULES.md为准。

应用使用同一个runtime.publish_pack，并只绑定当前对象。每次应用取得新版本，旧版本不覆盖；不能以错误图改世界。撤销/重做只影响草稿，不撤销已发生的世界模拟。未发布草稿不落盘，界面已经明确提示。

## 输入、暂停与数据

世界点击经反向显示变换得到格坐标，再交给PlaySession。左键由当前工具决定操作，右键拾取；界面点击不传给世界。织律台/文件选择/确认弹窗暂停模拟并关闭角色控制，关闭后恢复此前暂停状态。参数文本正在输入时不触发E/Tab全局快捷键。

存档使用既有rw.play/0.1与CheckpointFiles，未另造格式。坏存档不能覆盖正在运行的世界；备份恢复须明确操作。导入律卷验证大小与已有运行器权限，不自动绑定；导出默认拒绝覆盖，UI通过原生保存对话框确认覆盖。没有账户服务、网络分享平台或任意脚本入口。

## 真实验证

新界面测试先观察到主场景缺失失败。随后复查发现并修复：小窗口下编辑内容把工具栏挤出屏幕；SpinBox以25步长配合最小值1导致125显示为126；参数输入E误关闭织律台。

界面原生断言35项、实际GraphEdit鼠标拖线/撤销和文件取消9项、真实鼠标/键盘完整探索23项。既有578项仍执行，当前共645项。Python新增9项打包和独立UI产物检查，累计138项。UI路线通过正式按钮应用可编辑吸水图、抽水途中保存重载、真实键盘进入遗迹、回营地点击交水；总水量6000。独立Python校验完整规则内容、目标、归属、位置和水量，不只相信屏幕文字。

软件GL/llvmpipe下取得实际world、loom、graph以及1152×720截图；确认底部操作区留在窗口内。它们是实际运行截图，但不代表用户显卡、DPI或手感验收；不宣称60FPS性能。

## 开发运行包

package_desktop.py只拷贝生产content/presentation/runtime/vendor和project.godot，拒绝符号链接及字体文件，不包含tests、scenarios、缓存。携带当前平台已校验的官方Godot4.6.1二进制，生成启动脚本、README、实际引擎许可与第三方版权、逐文件SHA256清单。

在临时副本中先编辑器导入，再从真实main启动并要求RULEWEAVER_APP_READY且无脚本错误，之后去掉.godot缓存，压缩后重新读取每个文件比对哈希。这是方便尝试的源码运行开发包，不是标准export模板导出、不含签名、不自动创建Release。远程Windows包只有对应CI实际成功后才能称通过。

正式素材/动画、声音、相机体验、角色手感、系统化制造/采集和进一步内容。当前携带的容器、灯与石料不代表完整生存成长。没有多个快捷栏槽位管理或完整背包界面；有已验证的库存数据和当前选择显示。没有将高级图中任意自创外形动态注册为新物质。当前源码继续同一分支，不合并main、不发布Stable。
