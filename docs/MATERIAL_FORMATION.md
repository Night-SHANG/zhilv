# v0.17 凝结地形、回收与连续搭路

当前世界和规则执行器不变。新增cell_empty、terrain_is、form_material、recover_material四个受限原语；它们仍可与移动、发光、判断和已封装词条一起组合。

受信材料定义bound_water_units：1到1000的整数，当前core:water_crystal=500。凝结从同一容器扣水并形成实心地块；回收移除对应材料并返还水。人工挖碎只释放水，不同时掉落封水材料。总账包含水层、容器、地形及库存材料封水。

所有动作按原事务执行：先操作暂存地形/水/实例，完整校验后统一提交。后续移动和排水读取本组已暂存地形，不能穿过刚造出的台阶或向实心地块排水。角色身体、已有地块、造物、1单位残水、资源不足、容量不足、边界、地形/水层预算均保持失败原子性。

同一模拟步所有造物读快照，按稳定ID提交。两台造物争同一格时只成功的一台付费；条件成立不等于提交成功。一拍预演仍只改变副本。材料单位不是玩家可通过命令改写的价格。

实际路线继承空包采集制作、排水、遗迹到访、营地交水和下层补给四目标，然后回收原灯和容器，搭两级台阶，保存恢复，原生角色跳到(0,-3)。凝结路线封存1000水；普通石块路线消耗两块既有石料。两种路线总水6000，目标检查到访和光照而非配方。移动+凝结+发光组合也已验证，资源用完时移动不能部分提交。

真实v0.16原生产物保存为fixtures/legacy_v016_workspace.json，校验恢复后世界、编辑态、时钟、速度、规则和已有四目标不变。场景v3仅声明v1/v2前缀兼容；旧档不能声称完成第五目标。F5保存升级后不保证旧程序可读。
